# VPN

Автоматическое обновление VLESS прокси каждые 30 минут.

## Источники
- [AvenCores/goida-vpn-configs](https://github.com/AvenCores/goida-vpn-configs)
- [ShatakVPN/ConfigForge-V2Ray](https://github.com/ShatakVPN/ConfigForge-V2Ray)
- [Hidashimora/free-vpn-anti-rkn](https://github.com/Hidashimora/free-vpn-anti-rkn)
- [igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia)

## Выходные файлы
- `Githubmirror/Sub/BlankedVPN/sub.txt` - подписка в base64
- `Githubmirror/Sub/BlankedVPN/sub.decoded.txt` - декодированная подписка
- `Githubmirror/Sub/BlankedVPN/servers_info.json` - информация о серверах

## Автоматизация
GitHub Actions запускает обновление каждые 30 минут.
